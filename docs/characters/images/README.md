# Character Wiki images

Le pagine Paragon puntano a:

```text
docs/characters/images/paragon/<slug>.png
```

La v0.7 include una **Wiki card generata** per ogni asset base. Non è artwork promozionale e non tenta di ricostruire il design visivo del personaggio.

## Sostituzione consigliata

Per una Wiki definitiva, sostituire ogni card con uno screenshot prodotto direttamente dal progetto Unreal che usa l'asset Paragon già importato.

Formato consigliato:

- 1200×630 o 1024×1024;
- personaggio intero o mezzo busto;
- camera e illuminazione coerenti per tutto il roster;
- sfondo neutro;
- stesso filename;
- niente HUD;
- mantenere il nome Paragon soltanto come `Asset Base` finché l'identità RT non è approvata.

In questo modo i Markdown non cambiano quando viene aggiornata l'immagine.
